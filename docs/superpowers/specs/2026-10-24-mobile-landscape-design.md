# 手机横屏优先适配设计

## 目标

在不改变桌面端视觉和交互的前提下，将《黄昏围城》调整为手机横屏优先体验：手机竖屏先显示转屏提示，用户仍可选择继续；手机横屏保留完整 16:9 剧情画面，并提高工具栏、字幕、选项和弹层在矮屏及刘海屏上的可用性。

## 约束

- 桌面端布局、剧情、素材和交互保持不变。
- 不强制调用浏览器方向锁定 API；手机浏览器对此支持不稳定。
- 竖屏提示可以跳过，跳过只在本次页面会话内生效。
- 横屏画面保持 16:9，不拉伸、不裁成竖图。
- 关键控件避开 `safe-area-inset-*`，触控高度不少于 44px。

## 方案

采用“方向引导层 + CSS 专用状态”的渐进增强方案。布局脚本只负责标记 `portrait`、`mobile-landscape`、`short` 和 `portrait-allowed` 状态；视觉调整集中在样式表中。手机竖屏默认由高层级引导层遮住游戏，选择继续后沿用已有竖屏降级布局。手机横屏通过独立规则压缩非关键留白、工具栏、字幕和选项，同时保留完整电影画框。

未采用自动锁屏，因为 iOS Safari 和普通网页上下文不能可靠锁定方向；也未另做第二套页面，以避免剧情引擎和后续素材更新出现双份维护。

## 验收

- 390×844：显示转屏提示；“仍以竖屏继续”可关闭提示并操作首页。
- 844×390：完整显示 16:9 画框，工具栏避开安全区，字幕和选项不溢出。
- 667×375：小屏横屏仍可点击工具栏与选项，长内容可局部滚动。
- 桌面 1440×900：首页及剧情布局与改动前一致。
