# 黄昏围城

一个围绕老年亲密关系、家庭沟通与现实选择展开的双视角互动叙事作品。

## 在线体验

启用 GitHub Pages 后，可通过仓库的 Pages 地址直接访问。

建议使用电脑横屏或手机横屏，并开启声音体验。

## 项目结构

- `index.html`：GitHub Pages 发布入口
- `img/`：剧情场景与可点击物件图片
- `audio/`：背景音乐与交互音效
- `src/`：剧情、样式和交互逻辑源文件
- `build.py`：构建脚本
- `downloads/黄昏围城_单文件版.html`：可离线打开的单文件版本

## 本地预览

在项目目录启动任意静态文件服务器，然后在浏览器中访问 `index.html`。直接双击单文件版本也可以离线体验。

## 技术说明

本项目是纯前端静态网站，进度保存在浏览器本地存储中，不会上传个人信息。
